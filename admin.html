🔐 Admin Login

Ei panel-e product name, price, image, stock - sob kichu update korte parbe. Customers er kono write access nei.

Token tomar browser-e sessionStorage-e thake, repo-te save hoy na. Tab bondho korlei muche jay.
⚠️ Token ki rokom lagbe?
GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
• Repository access: Only select repositories → ei repo-ta select
• Permissions → Contents: Read and write (shudhu etai)
• Expiration: 30 din (naror age notun banabe)

🔒 Token kokhono commit hoy na. Shudhu tomar device-e thake.
